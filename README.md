# take6mod
Launcher pour Grand Theft Auto VI. Code source mis a disposition.


Take6Mod est un launcher conçu pour Grand Theft Auto VI, destiné aux développeurs souhaitant recompiler le jeu en attendant sa sortie officielle sur PC.

Take6Mod vous fait gagner du temps en vous permettant de disposer dès maintenant de votre launcher, accompagné de son interface dédiée, afin que vous puissiez vous concentrer sur le développement plutôt que sur la création de votre interface.
